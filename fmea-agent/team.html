获取邮箱授权码

QQ邮箱：

  1. 登录 mail.qq.com
  2. 进入「设置」→「账户」
  3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
  4. 开启「IMAP/SMTP服务」
  5. 按提示发送短信，获取授权码

163邮箱：

  1. 登录 mail.163.com
  2. 进入「设置」→「POP3/SMTP/IMAP」
  3. 开启「IMAP/SMTP服务」
  4. 获取授权码（部分版本需要设置客户端授权密码）

授权码是一串字母和数字，不是邮箱登录密码。

获取知识库授权码

登录 WeKnora 知识库：

  1. 访问 http://10.180.17.11:81
  2. 使用你的账号登录
  3. 进入「账户信息」页面
  4. 复制 X-API-Key 字段
  5. 粘贴到此处

联系管理员获取：

如果没有账号，请联系系统管理员为你开通 WeKnora 知识库账号并获取 API Key。

授权码形如 sk-xxxxx，用于调用知识库检索接口。
